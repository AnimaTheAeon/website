Mutagen

Mutate your save.

A save editor for TMNT: Splintered Fate. It finds your save and your game folder by itself, and every change is backed up and checked.

Download onNexus Mods
WindowsSteam
Mutagen–▢✕
Overview

Every currency, in one place.

Dragon Coins and Dreamer Coins, every upgrade material, and each hero’s talismans and astral wraps. Type a number or tap +1,000. Your earned and spent history stays intact.

Current run

Swap heroes mid-run.

Drag a hero’s portrait onto Current character to switch who you’re playing. Add, remove and level run powers, and set Scrap, Lucky Dice and revives. Karai and Shredder show up here when the mod is installed.

Upgrades & artifacts

Click a bar. Set the level.

Every shop upgrade across Combat, Turtles, Fortune and Inspirations, plus all your artifacts. Max a whole tab in one click.

Advanced

Tune the game itself.

Change hero base stats and power values in the game files. It’s applied as a patch you can undo, and Restore original files puts back the exact original.

Safe by default.

Your save is checked before and after every change.

Game closed first

Won’t save while the game is running, and notices if the game saved after you opened the file.

Backed up every time

Every save is backed up before writing. The last 25 are kept.

Verified

Each file is read back and checked after writing, so a bad save is never left behind.
